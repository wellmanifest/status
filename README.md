# wellmanifest/status

`wellmanifest/status` is the HOME pack for portable status-cycle snapshots and
transitions. Product runtimes ADOPT it; the standard does not execute work or
grant authority.

The first governed ticket will define the closed status envelope, deterministic
transition checks, LLM propose-only projection, and composition with
`wellmanifest/dsl`, `wellmanifest/jsonl`, and domain lifecycle packs.
